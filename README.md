# RHC CTF Game

Standalone, locally-runnable releases of Robotic Hacking Community CTF games.

## Releases

- [`dc34/`](dc34/) — RoboHack AI CTF, from DEF CON 34. A single-player MuJoCo
  simulation with a VLM-powered robot brain and five challenges (prompt
  injection, privileged API abuse, adversarial patches, a hidden ROS 2 topic,
  and model poisoning). See [`dc34/README.md`](dc34/README.md) to get started.
